# Attendance

We are rolling our own custom app for tracking attendance. The server
portion of this app will be hosted here at the `/apps/attendance` URL.

For now we will keep this app extremely simple. The only endpoints are:

/apps/attendance/<token>

where the token is a large url-safe random number generated by some
other software.

GET: Render a PWA that allows people to enter their name and UC Davis
email address. Save these in local storage so that it can be
pre-filled next time the user hits it.

POST: Sends their name and UC Davis email address, both must be filled
out.

To store this data, we're going to append a row to a Google
Sheet. Using Google Sheets is important because of FERPA regulations,
and Google Sheets are an approved way to store student records. We
can't store this data anywhere else.
