# Project: kingst-ucdavis

This repo contains the public facing website for professor Sam King,
hosted at bob.cs.ucdavis.edu. This is a python flask project.

Overall it contains a basic academic website and course materials for
each of the classes he has taught at UC Davis.

## **IMPORTANT** Rules for Agentic Programming Tools:

* You may NOT use my credentials to access github, but you can access
  open repos without my credentials

* You may _never_ commit code, even on local repos. I always want to
  check your work so don't ever commit code even on local repos.

* You man _never_ deploy this webapp.

* You may _never_ use forced unwraps. I might use them every once in a
  while when I write code manually but I don't want you to ever use
  them.

* Only make changes if I ask you to explicitly. Oftentimes I'm looking
  to get help understanding the code and coming up with porting
  strategies, so if I want you to change something I will ask
  explicitly.

* I'm making changes manually as we go, always re-read files before
  modifying them. Never assume that you're the only one making
  changes.

* Ask questions! If something isn't clear please ask clarifying
  questions before diving in. I'm here to help.

* There will be times when I want you to run for a long time. In these
  situations I'll break down the task into subtasks with exit criteria
  for each. When this happens, make sure to ask any questions at the
  very beginning of the task since I'll usually walk away and expect
  you to operate autonomously.
